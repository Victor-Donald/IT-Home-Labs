Active Directory &
Windows 11 Support Lab

Built and supported a virtualized Windows Server and Windows 11 environment to practice enterprise Active Directory administration, DNS troubleshooting, authentication, account access, permissions, and Tier 1 desktop support workflows.

LAB OBJECTIVE

Simulating an Enterprise Support Environment

The objective of this lab was to build a functional Windows domain environment and use it to practice common enterprise IT support tasks.

The environment was used to troubleshoot user authentication, domain connectivity, DNS resolution, account access, shared resources, and Windows client issues using a structured diagnostic process.

LAB ENVIRONMENT

Virtualized Enterprise Environment

The environment was built using VirtualBox and Windows virtual machines to simulate a small enterprise domain.

TROUBLESHOOTING

Problems Diagnosed & Verified

The lab was used to practice systematic troubleshooting rather than simply configuring the environment.

01

DNS Resolution

Used nslookup and DNS queries to verify that the client could resolve the Active Directory domain.

02

Domain Connectivity

Used network diagnostic commands including ping and ipconfig to isolate connectivity and TCP/IP issues.

03

AD DNS Records

Verified Active Directory DNS service records, including LDAP-related SRV records required for domain services.

04

Authentication

Tested domain authentication and successfully signed into CLIENT02 using the ADLAB\Administrator account.

05

Resource Access

Tested access to shared resources and verified permissions using the server's network address.

06

Verification

Repeated diagnostic tests after remediation to confirm that the environment was operating correctly.

TIER 1 SUPPORT APPLICATION

How This Lab Applies to Help Desk Support

The lab demonstrates a structured approach to common user-support issues involving account access, authentication, connectivity, DNS, Windows clients, and shared resources.

When troubleshooting a reported issue, I practice identifying the user's symptoms, gathering relevant information, testing the most likely causes, applying remediation, verifying the result, and documenting the resolution.

USER ISSUE

Identify

Determine what the user is experiencing and identify the affected account, system, or resource.

DIAGNOSIS

Isolate

Use appropriate Windows, DNS, and network diagnostics to isolate the source of the problem.

RESOLUTION

Verify

Apply the appropriate corrective action and confirm that the user or system can perform the required task.
